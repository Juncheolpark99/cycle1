# cycle1 — Gas Turbine Performance Analysis

Python 기반 항공용 가스터빈 성능해석 프로젝트의 첫 번째 실행 가능한 초안(v0.1.0)입니다.

## 범위 (v0.1.0)

- 구현: 정상상태 **설계점(Design Point)** 비혼합, 분리배기, 2축 터보팬(단순화된 0-D 열역학 모델)
- 모델: 입구/팬/고압압축기/연소기/HPT/LPT/코어·바이패스 노즐
- 산출물: 정지점 전온·전압, 연료공기비, 추력, TSFC, 축 동력 잔차, 질량·에너지 검증
- 추후 구현: Off-Design, 팬·압축기·터빈 맵 보간, 구성품 매칭, 블리드/냉각, 성능맵, 민감도/불확실성, 시험·CFD 보정
- **주의**: 실제 엔진 설계·시험 안전성 또는 인증에 사용하기 전에 물성 변화, 냉각/추기, 믹서, 맵 및 보정 모델을 추가하고 시험 검증해야 합니다.

## 빠른 실행

Python >= 3.10, 외부 패키지 불필요.

```bash
python -m pip install -e .
cycle1
python -m unittest discover -s tests -v
```

소스 저장소에서 설치하지 않고 실행: `PYTHONPATH=src python -m cycle1.cli` (Windows PowerShell: `$env:PYTHONPATH="src"; python -m cycle1.cli`).

## 모델 정의

- 기준: 완전기체, 상수 `cp`, `gamma`, 기계 효율, 연소효율, 일정한 구성품 효율
- 입력: 고도, 마하수, 공기유량, 바이패스비, 팬 및 HPC 압력비, 압축기·터빈 효율, Tt4 등
- 흐름: 팬 통과 후 코어/바이패스로 분리, HPC → 연소기 → HPT → LPT → 코어 노즐
- HPT가 HPC를, LPT가 전체 팬 유량의 팬 일을 구동 (독립된 두 축)
- 추력: 코어·바이패스 제트 운동량 + 노즐 압력추력 − 흡입 운동량
- `TSFC`: kg/(N·s); 함께 kg/(kN·h) 표시
- 모든 압력은 절대압력(Pa), 온도 K, 질량유량 kg/s입니다.
- 노즐 출구 면적은 질량유량·출구밀도·속도에서 역산하며 고정 면적/맵 매칭은 수행하지 않습니다.

## 구조

```
src/cycle1/
  physics.py   # 순수 물리 구성품 및 데이터 구조
  solver.py    # 설계점 사이클 오케스트레이션/보존 잔차
  cli.py       # 실행 예제
tests/         # 단위 및 보존 테스트
```

아키텍처 원칙: **물리 구성품 계산과 수치적 해석/사이클 조립을 분리**합니다. 이후 Off-Design 해법(비선형 잔차/매칭)을 별도 모듈로 확장합니다.

## 초기 모델의 제한

- 연료 질량은 코어 노즐 질량유량에 더하며, 연소기 1차 에너지 보존으로 연료비를 계산합니다.
- 연소 전후 `cp` 및 `gamma` 일정 가정, 연소 생성물의 조성 변화 미반영
- 노즐은 총압 대비 배압으로 choked 여부를 구분하는 간이 모델이며, 독립 노즐 목면적·유량 capacity 및 맵 매칭 모델은 없습니다.
- 수렴을 요구하는 Off-Design 동작이나 과도 시동 해석은 현재 버전에서 지원하지 않습니다.
